# MonitorMate support

Version 1.0.0 is prepared as a GitHub preview, not a certified stable release.
There is no time-limited trial in the reviewed source. Future paid Store distribution
does not establish a current paid support service or response guarantee.

Use the local [troubleshooting and removal guide](store/SUPPORT.md) for DDC/CI,
gamma restoration, focus exits, startup, data locations and uninstall behavior.
Check [known issues](docs/AUDIT.md) before filing a duplicate.

## Bug reports

After the repository is available, use its bug-report form. Include version/revision,
Windows build, monitor model, cable/dock, display scale, reproduction steps and
expected/actual behavior. Review diagnostics before sharing them. Do not upload
the entire data folder, coordinates or private screenshots.

The proposed repository is `benedictusrey/MonitorMate`; public availability was
not verified during this preparation. Maintainer: [@benedictusrey](https://github.com/benedictusrey).
Do not invent an email address or promise a response time.

Security concerns follow [SECURITY.md](SECURITY.md). Current data practices are
described in [PRIVACY.md](PRIVACY.md).
