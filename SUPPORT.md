# MonitorMate support

MonitorMate v1.0.0 is a public GitHub preview for feedback, maintained by
Benedictus RH ([@benedictusrey](https://github.com/benedictusrey)). It has no timed
trial, paid support commitment or guaranteed response time.

## Before reporting a problem

Use the current [release downloads](https://github.com/benedictusrey/MonitorMate/releases/tag/v1.0.0)
and record their SHA-256: refreshed previews keep the v1.0.0 version. Read
[installation](docs/INSTALLATION.md), [troubleshooting](store/SUPPORT.md) and
[platform limits](docs/PORTABLE_PREVIEW.md). Linux/macOS reminders do not include
the Windows display controls, focus overlay or tray behavior.

## Report a bug

Open a [MonitorMate issue](https://github.com/benedictusrey/MonitorMate/issues/new/choose).
Include your operating system, package checksum or source revision, steps,
expected result and actual result. For Windows display problems, add the monitor
model, cable/dock, graphics driver, HDR state and exact control-status message.
A readable gamma ramp alone does not establish write support.

Share a small, sanitized example. Review diagnostics for coordinates, device
identifiers and personal paths. Do not upload your entire data folder or private
screenshots. Report vulnerabilities through [the private security channel](SECURITY.md).

MonitorMate is a comfort utility. It does not diagnose or treat medical conditions.
