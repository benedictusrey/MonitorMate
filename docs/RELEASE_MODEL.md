# Release model

[MonitorMate v1.0.0](https://github.com/benedictusrey/MonitorMate/releases/tag/v1.0.0)
is a public GitHub preview without a timed trial. The adopted [MIT License](../LICENSE)
is credited to **Benedictus RH (@benedictusrey)**. Windows provides the full app;
Linux/macOS provide the approved smaller reminder preview.

The owner requested that all versions remain v1.0.0. A refreshed download can
therefore differ from an older file with the same name. Release notes record
source provenance, and `SHA256SUMS.txt` identifies the current package bytes.
Use both when reporting a problem. The preview remains a pre-release, with the
[verification limits](VERIFICATION.md) stated openly.

A paid official Microsoft Store edition is a future plan. Pricing, support terms
and purchase integration are undecided. MIT permits others to build and
redistribute the source, including commercially, subject to its notice terms.
No expiry, payment enforcement or Store entitlement integration is included.
