# Release model

The owner selected MIT and requested a v1.0.0 GitHub preview without a timed trial.
The [LICENSE](../LICENSE) is credited to **Benedictus RH (@benedictusrey)**.

The preview is not published. Native UI/hardware acceptance and Linux/macOS
implementation remain release gates. See [readiness](RELEASE_READINESS.md).

A paid official Microsoft Store edition is a future plan. Pricing, support terms
and purchase integration remain undecided. MIT permits others to build and
redistribute the software, including commercially, subject to the license terms.
No expiration, payment code or Store entitlement integration was added.
