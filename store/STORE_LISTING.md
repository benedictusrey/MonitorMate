## Short description

Display brightness, warmth, breaks and focus in one Windows utility.

## Full description draft

MonitorMate combines monitor brightness and contrast on supported DDC/CI
connections, gamma warmth, fixed or estimated solar schedules, break reminders
and reading-band/spotlight focus sessions. Local activity totals describe what
the app observes while running.

Core features work locally without a MonitorMate account. Settings, typed
coordinates, gamma records and usage history stay in the resolved app-data folder.
Hardware and driver support vary. The interface is dark-only and English-only.
HDR/ICC calibration is outside scope. No medical treatment benefit is claimed.
