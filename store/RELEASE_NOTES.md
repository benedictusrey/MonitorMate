# MonitorMate Store release notes proposal

No Store release date or paid package is established. The immediate v1.0.0 plan
is a GitHub preview. No timed trial or expiry is added.

The local source includes DDC/CI brightness, gamma warmth, fixed/solar scheduling,
break reminders, focus overlays, local activity history, tray and global shortcuts.
Hardware controls depend on monitor/driver support. Packaged startup, HDR/ICC,
accessibility and mixed-DPI verification remain incomplete.

Before using these notes, resolve [audit blockers](../docs/AUDIT.md), confirm
commercial terms/source licensing and complete the [Store checklist](RELEASE_CHECKLIST.md).
The public-facing GitHub preview notes are [RELEASE_NOTES.md](../RELEASE_NOTES.md).
